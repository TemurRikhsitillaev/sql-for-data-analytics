SQL: ЗАДАЧИ ПО SELECT
База: Northwind (PostgreSQL) + users, events
Темы: SELECT, FROM, алиасы, выражения, кавычки, DISTINCT, ORDER BY, LIMIT, OFFSET
WHERE не используем (кроме задачи 7).

============================================================
УРОВЕНЬ 1. БАЗОВЫЙ SELECT
============================================================

1. Выведи имя, фамилию и должность всех сотрудников.
   Таблица: employees (first_name, last_name, title)

2. Выведи все колонки таблицы categories, а затем только
   названия категорий (category_name).

3. Выведи название, страну и город всех поставщиков.
   Таблица: suppliers (company_name, country, city)

============================================================
УРОВЕНЬ 2. ВЫРАЖЕНИЯ И АЛИАСЫ
============================================================

4. Для каждого товара выведи название и цену со скидкой 15%
   под алиасом sale_price, округлённую до 2 знаков.
   Подсказка: unit_price имеет тип real, нужен ::numeric.

5. Выведи сотрудников одной колонкой в формате "Фамилия, Имя"
   под алиасом "Сотрудник", отсортируй по фамилии.

6. Из order_details выведи order_id, product_id и сумму строки
   заказа unit_price * quantity * (1 - discount)
   под алиасом line_total.

7. Для товаров выведи units_in_stock / reorder_level дважды:
   как есть и с приведением к numeric. Сравни результаты
   и объясни разницу. Строки с reorder_level = 0 отфильтруй.

8. Выведи название товара под алиасом "Название товара"

9. Выведи названия товаров и рядом колонку-константу с текстом
