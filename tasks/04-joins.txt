SQL: ЗАДАЧИ ПО JOIN
База: Northwind (PostgreSQL) + users, events
Темы: INNER JOIN, LEFT JOIN, несколько таблиц, JOIN + агрегаты

============================================================
INNER JOIN
============================================================

1. Товары с названиями категорий: product_name, category_name,
   unit_price. Только те, что продаются, по алфавиту.

2. Заказы с названиями компаний-клиентов: order_id,
   order_date, company_name, country. Топ-10 самых свежих.

3. Заказы с именем сотрудника, который их оформил: order_id,
   order_date и «Фамилия Имя» одной колонкой.
   Первые 20 по дате.

4. Позиции заказа 10248: название товара, количество, цена,
   сумма позиции (округли до 2 знаков).

5. Товары с названием категории и названием поставщика
   (suppliers.company_name). Только категория Beverages.

============================================================
LEFT JOIN
============================================================

6. Все клиенты и количество их заказов. Клиенты без заказов
   должны быть с нулём. Сортировка по количеству по убыванию.

7. Клиенты, которые ни разу ничего не заказывали.

8. Товары, которые ни разу не продавались
   (нет строк в order_details).

9. Все категории и количество товаров в каждой,
   включая категории без товаров.

10. Пользователи из users с количеством их событий, включая
    тех, у кого событий нет. Топ-20 по количеству.

============================================================
JOIN + АГРЕГАТЫ
============================================================

11. Выручка по категориям: category_name, выручка
    (unit_price * quantity * (1 - discount), округли),
    количество разных заказов. От большей выручки.

12. Топ-10 товаров по выручке: название, категория, выручка.

13. Топ-10 клиентов по сумме заказов: название компании,
    страна, сумма, количество заказов.

14. Сотрудники и количество оформленных ими заказов:
    «Фамилия Имя», количество. От большего.

15. Выручка по странам клиентов за 1997 год: страна, выручка,
    количество клиентов.

============================================================
НЕСКОЛЬКО ТАБЛИЦ
============================================================

16. Для каждого заказа 1998 года: order_id, название компании,
    страна доставки, сумма заказа. Топ-10 по сумме.

17. Какие товары покупали клиенты из Германии (customers.country,
    не ship_country): название товара, суммарное количество
    единиц. Топ-10.

18. Для каждой категории: название, количество товаров,
    количество разных заказов, в которых эти товары
    встречались.

============================================================
АНАЛИТИКА НА EVENTS
============================================================

19. Топ-10 просматриваемых товаров: product_name, количество
    просмотров. Отдельным запросом — топ-10 по добавлениям
    в корзину. Одним запросом научимся позже.

20. Количество событий по странам пользователей: страна,
    количество событий, количество разных пользователей.
    От большего количества событий.
